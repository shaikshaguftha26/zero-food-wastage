# Zero Food Waste 🌱

Zero Food Waste is a web-based platform designed to reduce food waste by connecting food donors with people in need. It encourages food sharing and promotes sustainability.

## Features
- Donate surplus food.
- Request available food.
- Interactive map for locating food donations.
- User dashboards and admin management.

## Technologies Used
- HTML, CSS, JavaScript
- Leaflet.js
- OpenStreetMap

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.

## Objective
To minimize food waste and help communities by making surplus food accessible to those who need it.
